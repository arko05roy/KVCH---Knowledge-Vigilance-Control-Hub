## 2. Where & How Reports Are Generated in the KVCH Architecture

### 1. Dynamic Web App AI Report Pipeline (`web/lib/ai/`)
- **Generator**: [`web/lib/ai/report-generator.ts`](file:///Users/ayush/Desktop/KVCH---Knowledge-Vigilance-Control-Hub/web/lib/ai/report-generator.ts)
- **Function**: `generateAllRoleReports(finding: FindingEnvelope)`
- **Mechanism**: Ingests telemetry envelopes (`kvch.finding/v1`) from the Judge Kernel or live scanner, executes multi-role prompting via Ollama / Groq Key Pool, applies asset criticality scaling (Local Laptop vs Production Infrastructure), and returns the 4-role package.
- **Frontend Presentation**: Rendered through [`web/components/ai-report-card.tsx`](file:///Users/ayush/Desktop/KVCH---Knowledge-Vigilance-Control-Hub/web/components/ai-report-card.tsx) across the four user dashboard portals:
  - `/intern/dashboard`
  - `/sr-dev/dashboard`
  - `/hr/dashboard`
  - `/management/dashboard`

### 2. Static & Demo Seed Data (`web/lib/demo-data.ts`)
- **Location**: [`web/lib/demo-data.ts`](file:///Users/ayush/Desktop/KVCH---Knowledge-Vigilance-Control-Hub/web/lib/demo-data.ts)
- **Constant**: `DEMO_REPORTS`
- **Mechanism**: Serves pre-compiled, deterministic 120-minute sandbox attack simulation intelligence to ensure that dashboards operate seamlessly even in offline or air-gapped demonstration environments.

### 3. Backend Python Engine (`External/`)
- **Generator**: [`External/unified_kvch_security_engine.py`](file:///Users/ayush/Desktop/KVCH---Knowledge-Vigilance-Control-Hub/External/unified_kvch_security_engine.py) & [`External/utils/report_generator.py`](file:///Users/ayush/Desktop/KVCH---Knowledge-Vigilance-Control-Hub/External/utils/report_generator.py)
- **Output**: [`External/reports/report.json`](file:///Users/ayush/Desktop/KVCH---Knowledge-Vigilance-Control-Hub/External/reports/report.json)
- **Mechanism**: Background daemon periodically executes all 10 extensions (`attack-surface-scanner`, `vpn-crypto-analyzer`, `phishing-hunter`, `threat-hunter-3000`, `malware-analyzer`, `credential-exposure-auditor`, `supply-chain-auditor`, `cookie-xss-auditor`, `aegisdb-zerotrust`, `edgeguard-sentinel`) and compiles finding envelopes.
